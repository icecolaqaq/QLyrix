# QLyrix

![][record]

## 项目概述
QLyrix 是一个类似Apple Music的QQMusic外置歌词播放器

## 技术栈
- Electron-Vite 
- ElementUI 
- VUE3 

## Note
QQ音乐 21.31 win11 下测试通过，仅支持 Windows 平台

## 食用方法
1.  [下载](https://github.com/icecolaqaq/QLyrix/releases)并安装
2. 打开QQ音乐
3. 运行 QLyrix 

### 环境要求
- **操作系统**：Windows
- **.NET 运行时**：.NET 9.0

## 鸣谢
- [Apple Music-like Lyrics](https://github.com/Steve-xmh/applemusic-like-lyrics/)：歌词、背景组件
- [AMLL Player](https://github.com/Steve-xmh/applemusic-like-lyrics/tree/full-refractor/packages/player)：设计参考
- [NetEase-Cloud-Music-DiscordRPC](https://github.com/Kxnrl/NetEase-Cloud-Music-DiscordRPC/)：控制部分代码实现
- [QQMusicApi](https://github.com/luren-dc/QQMusicApi/tree/main):歌词获取、解密实现
